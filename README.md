# 💰 Fluxo de Caixa em Python

Projeto desenvolvido em **Python** com o objetivo de praticar programação e criar um sistema simples para controle de fluxo de caixa.

O sistema permite cadastrar movimentações financeiras, identificando se são **lucros ou gastos**, além de informar a descrição e a origem de cada movimentação. Ao final, o programa calcula automaticamente o saldo e também gera uma planilha do **Excel** com os dados cadastrados.

## 🚀 Funcionalidades

* Cadastro de lucros e gastos
* Registro da descrição e origem da movimentação
* Cálculo automático do saldo
* Exibição das movimentações no terminal
* Geração automática de planilha Excel
* Formatação dos valores em Real (R$)
* Ajuste automático da largura das colunas

## 🛠️ Tecnologias utilizadas

* **Python**
* **OpenPyXL**
* **Excel**

## ▶️ Como executar

1. Clone este repositório:

```bash
git clone https://github.com/RichCoel1303/fluxodecaixa
```

2. Instale a biblioteca necessária:

```bash
pip install openpyxl
```

3. Execute o programa:

```bash
python fluxo_de_caixa.py
```

A planilha `fluxo_de_caixa.xlsx` será gerada automaticamente após a execução.
